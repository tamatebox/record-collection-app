# 追加機能の説明

このファイルでは、レコードコレクション管理アプリに新たに追加された機能について説明します。

## 1. 画像アップロード機能

### 機能概要
- レコード追加・編集時に画像をアップロードできるようになりました
- Discogsから取得した画像URLも自動的に保存されるようになりました
- アップロードされた画像は、サーバー側で適切なサイズに自動変換されます

### 使用方法
1. レコード追加/編集フォームで画像エリアの「+」ボタンをクリックします
2. 画像ファイルを選択してアップロードします
3. プレビューが表示され、フォーム送信時に画像データも送信されます

### 技術的な詳細
- フロントエンド側では `FormData` オブジェクトを使用して画像とデータを送信
- サーバー側では `multer` を使用して画像アップロードを処理
- アップロードされた画像は `sharp` ライブラリを使用してサムネイルを生成
- Discogsの画像URLからは `axios` を使用して画像をダウンロード

## 2. フォーム送信の改善

### 機能概要
- フォーム送信がボタンクリック時のみに行われるようになりました（Enterキーで自動送信されない）

### 技術的な詳細
- Reactの `useRef` と `useImperativeHandle` を使用して、親コンポーネントからフォーム送信を制御
- フォームの `onSubmit` イベントは直接発火させず、ボタンクリックのハンドラー経由で呼び出します

## セットアップ手順

1. 必要なパッケージをインストール:
   ```
   chmod +x install-packages.sh
   ./install-packages.sh
   ```

2. データベースマイグレーションを実行:
   ```
   node server/migrate-db.js
   ```

3. 画像保存用のディレクトリ構造を確認:
   ```
   mkdir -p server/public/images/record-covers/full-size
   mkdir -p server/public/images/record-covers/thumbnails
   ```

4. アプリケーションを起動:
   ```
   npm run server
   npm start
   ```

## 注意事項

1. 画像アップロードには以下の制限があります:
   - ファイルサイズ: 最大5MB
   - 対応形式: JPEG、PNG

2. 画像表示時にエラーが発生する場合は、以下を確認してください:
   - サーバーサイドの画像ディレクトリが存在すること
   - 画像ファイルがあること
   - 適切なパーミッションが設定されていること

3. Discogsからの画像取得には、有効なDiscogsトークンが必要です:
   - `.env` ファイルに `DISCOGS_PERSONAL_ACCESS_TOKEN` が設定されていることを確認
